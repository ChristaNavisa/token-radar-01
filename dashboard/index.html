Which pre-token protocol would be worth the most?

The watchlist is the floor: forty protocols DefiLlama already tracks as pre-token, every one of them ranked. Below the floor, the early radar adds the genuine pre-token protocols under $50M TVL — the ones a token launch would actually lift. Nothing ranks here because it is big; a protocol ranks because the record says its token would be worth something.

Each row carries the value the model puts on it, the multiple behind that value, and a farm plan costed in dollars — gas, locked capital, forgone yield and time — so you can see what chasing it would really cost before you decide whether it is worth chasing at all.

How the value is worked out

The value follows from three things the snapshot already knows: how much value a protocol holds (TVL), how fast that value is moving (the seven-day change), and how long it has run with no token (age). A category multiple turns TVL into a value — the geometric median of the market-cap-to-TVL ratios of the live-token protocols in that category, shrunk toward the global median — and growth and maturity adjust it. Nothing is hardcoded by name: the same arithmetic scores every protocol on the board.
